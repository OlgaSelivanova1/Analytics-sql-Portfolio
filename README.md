# ORACLE SQL Query - Портфолио аналитических задач для банковской сферы из пройденного интервью.
Список задач для прохождения интервью от компаниии "Эксперт ЭХД" с применением оконных функций и CTE.
СУБД ORACLE, использование таблицы DUAL с тестовыми данными.
## Что содержит данный репозиторий?
| Папка        | Contents                                                  |
| ------------- | --------------------------------------------------------- |
| `Analytics-sql-Portfolio/`   | Общая папка с файлом описания задач .docx и папка с решениями .sql     |
| `Zadachi.docx` | Текстовый файл с описанием постановки задач (количество: 5) |
| `scripts/`    | Schema setup, sample data, and test harness scripts       |
| `docs/`       | Design notes, ERD overview, performance tuning log        |
