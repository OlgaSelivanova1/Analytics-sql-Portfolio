### Задача №1
![Исходные данные](https://github.com/OlgaSelivanova1/Analytics-sql-Portfolio/blob/main/interview-tasks%20/bank-client/images.png/task_1_dscrptntbl.png)
 
Постановка задачи:
Есть автоматически рассчитанные значения атрибута 1 по сделкам, а есть ручные.
В ручных (mnl) есть дополнительный атрибут is_deleted_src
Is_deleted_src = 1 означает, что если такая сделка есть в авт.расчете, и ее оттуда нужно удалить(не использовать в результате отчета)
Задача вывести все сделки и значения их атрибутовс учетом ручных корректировок. Логика ручных корректировок: удалить из таблицы с автоматическими значениями записи, у которых Is_deleted_src= 1, а записям с Is_deleted_src= 0 вывести значение атрибута из mnl таблицы.
